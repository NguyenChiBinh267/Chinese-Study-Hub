# Các bước thực thi sau này — chưa chạy cloud

1. Chốt T068 account packet và quyền provision riêng. Giữ [runbook Sprint11](../sprint11/release-runbook.md) về managed baseline, backup, Auth restrictions và TLS. Không chạy native auth bootstrap lên Supabase managed.
2. Chọn immutable bundle có human receipts/rights/audio thật; review code/registry trong cùng artifact. `CSH_CONTENT_RELEASE=<pinned-id>`, `content:release check` phải PASS; không có CSH_CONTENT_TEST_ROOT/CSH_AUTH_TECHNICAL_FIXTURE/CSH_LOCAL_* ở host. Tracing chỉ đưa file server, không public media/keys. Không log DATABASE_URL hoặc chép keys vào NEXT_PUBLIC.
3. Backup/export mới + restore rehearsal riêng → migration/baseline được review → operator import immutable packages/exercises/bindings → runtime SELECT-only content và FORCE RLS. Tham khảo `scripts/release-runtime-inspection.sql`; đây là probe rollback, không phải production attestation. Chạy bằng runtime service/TLS đã cấu hình riêng, ví dụ `psql "service=csh_runtime" -X -v ON_ERROR_STOP=1 -v owner_a=<test-uuid-A> -v owner_b=<test-uuid-B> -f scripts/release-runtime-inspection.sql`. Chỉ dùng UUID thử được cấp quyền; không dùng migration/admin cho learner probes. Kiểm pooler transaction mode thực với application max=1 qua A → rollback lỗi → B → anonymous, rồi pool max=2; SQL session đơn không tự chứng minh pooler serverless. Chạy owner/non-owner/forged-body/origin/no-store/private-key E2E qua Auth thật. Ghi database OID/runtime OID/migration digest và metadata sanitized, không tự đổi local proof thành production proof.
4. `npm.cmd run security:preflight -- --config-only` là kiểm syntax/policy/release local; `npm.cmd run security:preflight` chỉ sau quyền cloud để kiểm live provider signup-disabled và production T009 proof. Không coi config-only là account/TLS/RLS proof. Owner UUID phải lấy từ provider được xác minh, signup/invites không dùng phải tắt; HTTPS origin/redirect exact allowlist.
5. **T069:** cùng SHA/lockfile/release/region/network/device trên các host account đủ T068. Phiên bounded 2–4 giờ có quyền; ghi cold open, warm auth/read/grade/idempotent retry/FSRS, pool connections, body/runtime/build limits, memory/egress/usage, rollback và browser Windows/Android. Ghi mỗi sample + điều kiện và p50/p95 nếu số mẫu đủ; timeout/sleep là kết quả, không thay bằng latency giả. Không cố mua compute để pass. Chỉ khóa ADR-006 sau số đo thật; hiện chưa benchmark hoặc chọn host.
6. **T053:** owner phê duyệt exact SHA + approved release + managed migration/restore + host đã đo. Deploy được cấp quyền riêng, smoke login → Today → approved lesson → server grade/persist → FSRS/progress → logout/login, check no DRAFT/private leakage. Chưa thực hiện trong sprint.
7. **Rollback:** đổi code về artifact trước và CSH_CONTENT_RELEASE về bundle PUBLISHED trước đã pin; giữ forward schema tương thích. Withdrawal phải đổi registry state, dừng new attempts/content ở request sau, không xóa attempts/cards. Không tự down-migrate sau published history; migration007 rollback chủ động từ chối trường hợp này. Khi cần data recovery: chặn writes, snapshot lỗi, restore thử riêng và xin quyết định recovery trước khi ghi đè live.

T068 actual account, T009 managed runtime/TLS/pooler, T069 measurements và T053 authorization đều còn UNVERIFIED/PENDING. Các commands phía trên là chuẩn bị thực thi, không phải log đã chạy cloud.
